# みとろ養蜂場 公式サイト（第一案）

## 確認方法

`index.html` をブラウザで開くだけで確認できます。VS Codeの Live Server 拡張機能を使うと、編集内容がすぐ反映されます。

## ファイル

- `index.html`：文章とページ構造
- `style.css`：色、余白、レイアウト、スマホ対応
- `script.js`：スマホメニュー、スクロール演出、仮フォーム
- `images/`：本番写真の保存場所
- `admin/`：管理者専用画面（Cloudflare Accessで保護して使用）

## 第一案で仮になっているもの

- 養蜂場名、住所、文章、商品名
- 写真（外部の仮画像）
- 商品価格と商品詳細ページ
- オンラインショップ、問い合わせ送信機能

本番写真が決まったら `style.css` の `url(...)` を `url("images/hero.jpg")` のように差し替えられます。

## 管理画面（第一段階）

管理画面は `/admin/` で表示されます。画面内にパスワードや秘密情報は保存していません。

公開前に、Cloudflare Zero Trust の Access で次の設定が必要です。

1. `/admin/*` を保護対象にする
2. Allow ポリシーにはサイト所有者本人のメールアドレスだけを登録する
3. 認証方法は One-time PIN（メールに届く使い捨てコード）を有効にする
4. シークレットウィンドウで、未ログイン時に `/admin/` が開かないことを確認する

重要：Access の設定が完了するまでは `/admin/` は公開状態です。先に Access を設定してから管理画面を案内してください。
