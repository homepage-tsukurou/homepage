# ホームページつくろう

GitHubへそのままアップロードできる静的サイトです。

## ファイル構成

- index.html：ページ本文
- style.css：デザイン
- script.js：メニューと表示アニメーション
- images/：使用画像

## メールアドレスを設定するとき

使用するメールアドレスが決まったら、index.htmlの「お問い合わせ先」部分をメールリンクへ変更してください。
上部の「相談してみる」「まずは相談」ボタンも同じメールリンクへ変更できます。

## 公開方法

GitHubのリポジトリへ、このフォルダ内のファイルをすべてアップロードしてください。
Cloudflare Pagesではビルドコマンド不要、公開ディレクトリはルートのままで利用できます。
