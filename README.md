# ホームページつくろう

GitHubへそのままアップロードできる静的サイトです。

## ファイル構成

- index.html：ページ本文
- style.css：デザイン
- script.js：メニューと表示アニメーション
- images/：使用画像

## お問い合わせ先

「相談してみる」「まずは相談」「メールで相談する」の各ボタンは、
`homepage.tsukurou@gmail.com`宛てのメールリンクに設定しています。

## 公開方法

GitHubのリポジトリへ、このフォルダ内のファイルをすべてアップロードしてください。
Cloudflare Pagesではビルドコマンド不要、公開ディレクトリはルートのままで利用できます。
